# 公开版与竞赛交付包

公开版独立整理，未改写原 E_PACK、已上板文件、报告或竞赛 RAR。

1. 移除 `wp4_gallery.h`、`wp4_quality_gallery.h` 中的历史人脸描述符。LBP 初始化不再预注册三位人员；模板匹配、阈值、现场注册和 SD 加载实现保持不变。活动源码与 baseline_src 均作相同处理。
2. 不包含旧 ELF，避免其携带历史内置描述符；请从源码重建。ready 保留原配套 bit、HDF 和初始化脚本。构建输出不会自动写回 ready。
3. 不包含现场照片、SD 身份库、训练原始图像、个人级验证预测 CSV 或训练 checkpoint。部署所需冻结权重仍在各版 PS 头文件和检测模型导出文件中，训练/导出代码也保留。重新训练需自备合法取得的数据，不能声称可以复现逐字节相同的训练结果。
4. 历史 `hardware/tb/cnn_vectors` 含来源尚未确认的图像输入及派生特征，因此未公开；相关历史测试需自行生成相应数据。其他已保留的合成向量不因此被宣称已全部回归。上述目录不参与正式硬件/PS 构建。
5. 旧打包回执、旧文件清单及测量补丁不作为公开版的验证证据；公开版保留完整测量源码，另生成自己的清单和验证记录。
6. Vivado 工程归档只用于查看和重建硬件，未包含实现运行缓存。PL 硬件输入未因公开整理发生变化。

原配置上板已验证；公开版更改了内置库初始化，需重新注册并进行自己的上板验收。UI 中的历史槽位名称属于标签，不代表已有对应人脸模板。
